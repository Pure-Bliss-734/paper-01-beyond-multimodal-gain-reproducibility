# Beyond Multimodal Gain

If an additional modality improves prediction, what does that gain tell us about the underlying state that matters for the task? This repository provides the simulations, compact inputs, and analysis code used to study that question with NHANES, CrossCheck, and MELD.

[Paper PDF](paper/Beyond_Multimodal_Gain.pdf) · [Reproduction instructions](reproduction/README.md) · [Download the release](https://github.com/Pure-Bliss-734/paper-01-beyond-multimodal-gain-reproducibility/releases/tag/v2026.11.26)

NHANES, MELD and CrossCheck analyses and simulations can be rerun from the supplied compact inputs.

The release contains the manuscript PDF and the reproduction ZIP.
